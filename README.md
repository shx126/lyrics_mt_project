# 🎵 带多线程支持的终端歌词播放器

一个基于 Linux 终端的同步歌词播放器，采用多线程架构，实现音频播放与歌词显示的精准同步。

## ✨ 功能特性

- **LRC 歌词解析**：支持标准 [mm:ss.xx] 时间戳格式，并自动按时间排序
- **实时高亮显示**：当前播放行以高亮样式突出显示，提升阅读体验
- **多语言支持**：完整 UTF-8 编码兼容，可正确渲染中、英、日、韩等语言歌词
- **多线程架构**：
  - 🕒 **定时线程**：精确监控音频播放进度
  - 👁️ **显示线程**：独立刷新终端界面，避免卡顿
- **音频播放**：通过 mplayer 在后台播放 .mp3 等音频文件（需预装）

## 🛠️ 编译与运行

### 1. 安装依赖

```bash
sudo apt update
sudo apt install mplayer
```

💡 `mplayer` 用于后台播放音频，若未安装将无法播放音乐。

### 2. 编译项目

```bash
make
```

编译成功后，可执行文件将生成于 `bin/lyrics_player`。

### 3. 运行程序

```bash
./bin/lyrics_player test_data/sample.mp3 test_data/sample.lrc
```

#### 参数说明：
- 第一个参数：音频文件路径（支持 .mp3, .wav 等 mplayer 支持的格式）
- 第二个参数：LRC 歌词文件路径（需与音频时间轴匹配）

## ⌨️ 控制方式

| 按键             | 功能            |
|------------------|-----------------|
| 空格             | 暂停 / 继续播放 |
| enter            | 退出程序        |

## 📝 注意事项

- 歌词文件必须为标准 LRC 格式，例如：

```
[00:12.30]这是第一句歌词
[00:15.60]这是第二句歌词
```

- 若终端显示乱码，请确保系统 locale 支持 UTF-8（推荐 `zh_CN.UTF-8` 或 `en_US.UTF-8`）
- 本程序仅在 Linux 终端环境下测试通过（如 Ubuntu、Debian）
